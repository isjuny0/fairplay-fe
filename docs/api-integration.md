# API 연동과 오류 처리

[README로 돌아가기](../README.md)

## 요청과 인증

- 기능별 API 모듈은 공통 `apiRequest`를 사용합니다. `VITE_API_BASE_URL`이 비어 있으면 같은 출처의 `/api`로 요청합니다. 로컬 Vite는 `VITE_API_PROXY_TARGET` 또는 기본값인 `http://localhost:8080`으로 전달합니다.
- 실제 요청은 세션 쿠키를 포함합니다. 쓰기 요청의 CSRF 토큰은 `/api/auth/csrf`에서 발급받아 서버가 지정한 헤더로 전달합니다.
- 일반 요청 본문은 JSON이며 파일과 메타데이터를 함께 보내는 요청에는 `FormData`를 사용합니다. 응답은 기본적으로 JSON으로 읽고, 파일 요청은 Blob으로 받습니다. `204` 응답은 `null`로 처리합니다.
- 미리보기 경로의 요청은 예시 API로 분기합니다. 가이드와 자유 탐색의 상태 범위는 [미리보기 문서](preview.md)에서 확인할 수 있습니다.

## 화면 상태와 오류

- 공통 요청 함수는 실패한 응답에서 HTTP 상태와 서버 오류 코드를 담은 `ApiError`를 전달합니다.
- 서버가 `INVALID_CSRF_TOKEN`을 반환하면 토큰을 다시 발급받아 해당 요청을 한 번 재시도합니다. `401`에서는 토큰을 지우고 세션 만료 이벤트를 전달합니다.
- 조회 훅은 조회 범위가 바뀌면 이전 범위의 응답을 화면에 표시하지 않습니다. 권한에 영향을 주는 조회는 진행 중인 요청만 공유하고, 일부 표시용 데이터는 짧게 재사용합니다.
- 작업·자료 등 버전을 확인하는 수정에서 충돌이 발생하면 최신 상태를 불러오고 입력을 복구할 수 있게 안내합니다. 상세 요청 경로와 화면별 처리 기준은 [기능 문서](features.md)에 정리되어 있습니다.
