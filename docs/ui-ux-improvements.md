# 화면별 UI/UX 개선

## 공통 규칙

- 모바일에서는 스페이스 상단의 메뉴 한 곳에서 스페이스 운영과 팀 메뉴를 탐색합니다. 현재 화면 이름과 선택 메뉴를 표시하며 Escape로 닫으면 메뉴 버튼으로 초점을 돌려줍니다.
- 표·타임라인의 실제 가로 넘침을 감지해 남은 열을 확인하는 방법을 안내합니다. 끝까지 이동하면 안내를 숨깁니다.
- 주요 등록 행동과 제목을 먼저 보여주고, 좁은 산출물 화면의 검색·새로고침 등 보조 행동은 다음 행으로 배치합니다.
- 비활성 참여자 삭제·팀 가입 버튼의 제한 사유를 화면에도 표시합니다. 기존 권한·완료·삭제 조건은 API와 도메인 규칙을 그대로 사용합니다.
- 공지 목록 응답이 현재 계약 형식과 다르면 공지 영역의 조회 오류로 처리해 스페이스 홈을 유지하고 재시도할 수 있습니다.

## 검증

`tests/e2e/experienceConsistency.spec.js`에서 모바일·데스크톱 메뉴 이동, 메뉴 초점 복귀, 필터 접기·해제, 등록 전 요약, 삭제 제한 사유, 읽음 피드백, 가로 스크롤 안내, 리포트 펼치기와 관리 단계 표시를 확인합니다. API 계약은 기존 단위 및 브라우저 회귀 검사를 함께 사용합니다.

- 단위 검사 187개 통과.
- 최종 사용성·모바일·권한·입력 동선 브라우저 검사 95개가 한 번의 실행에서 모두 통과했습니다.
- 신규 사용성 검사 14개와 모바일 화면 검사 20개를 포함한 브라우저 회귀 검사를 실행했습니다. 새 메뉴·기본 위젯·계산 내역 펼치기 동선과 현재 API 응답 형식에 맞춰 기존 검사도 갱신했습니다.
- 전체 검사에서 실패한 항목은 원인을 확인한 뒤 대상별로 재검증했습니다. 테스트 서버 연결 실패는 별도 서버를 유지한 실행으로 다시 확인했습니다.
- `npm run build`, `git diff --check` 통과.

실제 iOS·Android 기기의 키보드와 브라우저 동작은 실기기 확인이 필요합니다.

### 화면 간 간격 일관성 점검

- 모바일 팀 메뉴의 중복 좌우 여백을 없애 스페이스 메뉴와 같은 시작선에 배치하고, 팀·스페이스·관리자 메뉴 항목 높이를 44px로 맞췄습니다.
- 모바일 새로고침 버튼은 같은 행의 일반 버튼과 높이를 44px로 맞췄습니다. 데스크톱 아이콘 크기는 40px입니다.
- 공지·회의록의 목록 제목 아래 여백은 12px로 맞추고, 회의록 목록의 제목 구분선과 표 상단 구분선 중 표의 선만 유지합니다. 상세 화면의 구분선은 유지합니다.
- 공지·회의록·알림 페이지 이동 영역은 목록과 24px, 버튼 사이 16px, 버튼 높이 44px, 같은 글자 크기·안쪽 여백으로 통일합니다.
