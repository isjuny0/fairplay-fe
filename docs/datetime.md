# 날짜·시간 계약

[README로 돌아가기](../README.md)

서버와 주고받는 날짜·시간은 한국 시간 기준의 오프셋 없는 문자열입니다. 예시는 `2026-10-21T15:00:00`입니다. 날짜만 다루는 값은 `YYYY-MM-DD`를 사용합니다.

- 입력과 화면 표시에서는 한국 시간의 날짜와 시각을 유지합니다.
- 새 입력폼의 기본 시각은 `00:00`입니다. 날짜가 미리 채워지는 작업·스페이스·회의록 폼은 `defaultFormDateTime`으로 한국 날짜의 자정을 사용합니다. 날짜를 직접 입력하거나 달력에서 고른 뒤 처음 채워지는 시각과 빈 시간 선택기의 초기 선택도 `00:00`입니다.
- 수정 폼의 저장된 시각과 사용자가 직접 입력한 시각은 유지합니다. 작업의 선택 시간 입력을 비우면 수정 시 기존 시각, 새 작업은 `00:00`으로 저장합니다. 팀 캘린더의 빈 시간은 종일 일정이라는 의미를 유지합니다.
- 평가 일정은 기존 시작 가능 시각보다 앞서지 않는 날짜의 자정을 기본값으로 잡습니다. ‘현재 시간’ 버튼은 사용자가 직접 선택하면 실제 한국 현재 시각을 적용합니다.
- 마감 경과나 기간 비교를 위해 타임스탬프가 필요한 경우 `apiTimeToEpoch`가 문자열을 UTC+09:00으로 해석합니다.
- 현재 시각을 같은 API 형식으로 만들 때는 `koreanDateTime`을 사용합니다. 미리보기에서 생성하는 시각에도 같은 변환을 사용합니다.
