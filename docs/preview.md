## 미리보기 진입과 상태 관리

일반 미리보기 진입 주소는 `/preview`이며 `/preview/main`으로 이동합니다. 모든 데이터를 예시로 제공하며 실제 서버에 변경을 요청하지 않습니다. 헤더에는 `미리보기` 버튼만 표시하며, 역할·상황·예시 초기화를 떠 있는 설정 패널에서 변경하고 같은 패널 하단에서 미리보기를 종료합니다. 로그인 사용자는 헤더의 프로필 아이콘을 눌러 계정 메뉴에서 로그아웃합니다.

전시 가이드 진입 주소는 `/preview/exhibition`입니다. 전시 모드에서는 헤더에 `사용자 가이드` 버튼만 표시하며, 가이드 선택 창에서 미리보기를 종료할 수 있습니다. `자유 탐색 시작`을 선택하면 일반 미리보기로 전환합니다. 내부 화면 이동과 새로고침 시 전시 모드를 유지하고, `/preview`로 다시 진입하면 일반 미리보기로 전환합니다. 시작 화면은 팀원·관리자 탭에서 제목·목적·단계 수를 비교하는 목록으로 구성합니다. 현재 시작 가능한 가이드는 ‘작업 완료하기’·‘팀 자료 검색하기’·‘동료 평가 제출하기’·‘내 기여도 확인하기’·관리자용 ‘팀 진행 상황 살펴보기’·‘동료 평가 시작하기’·‘리포트 생성·공개하기’입니다. 준비 중 항목의 단계 수는 예정 값입니다. 현재 팀 홈 → 내 작업 → 문서 산출물 등록 → AI피드백 확인 → 수행 설명 저장 → 완료 → 진행률 비교를 안내합니다. 수행 설명과 문서 제목·본문은 가이드 예시로 자동 입력하고, 확인할 내용과 실제 버튼을 은은하게 강조합니다. 가이드는 위치만 안내하며 사용자가 화면의 저장·등록·완료 버튼을 직접 누릅니다. 실제 저장 성공을 확인해 다음 단계로 넘어갑니다. AI피드백은 예시 검토 요청 후 결과의 확인 완료 버튼을 눌러야 다음 단계로 진행하며, 실제 작업 완료의 필수 조건을 추가하지 않습니다. 가이드는 시작할 때마다 새 데이터로 첫 단계부터 진행하며 이어하기를 제공하지 않습니다. 가이드 진행 중 새로고침해도 첫 단계부터 다시 시작합니다. 자유 탐색과 데이터는 분리합니다. 실제 서버 저장·AI 호출은 수행하지 않습니다. 팀 자료 검색 가이드는 자료 확인 → 예시 질문 전송 → 답변 확인 → 근거 원문 확인의 4단계이며, 답변 없음·원문 조회 오류를 성공으로 처리하지 않습니다. 새로고침하면 선택한 시나리오의 첫 단계부터 다시 시작합니다.

## 가이드별 동작

동료 평가 제출 가이드는 평가 대상 확인 → 대상별 예시 점수·사유 저장 → 최종 제출 → 제출 결과 확인의 4단계입니다. 본인을 제외한 팀원을 각각 저장하고 실제 제출 확정 성공 후에만 완료합니다. 저장 실패·미저장 변경·제출 취소는 완료로 처리하지 않으며 실제 계정의 평가에는 반영되지 않습니다.

내 기여도 확인 가이드는 공개된 리포트의 개인별 100점 만점 종합점수, 항목별 원점수·비중·반영 점수, 중간·최종 동료 평가 항목별 평균, 반영된 완료 작업과 연결 문서를 순서대로 안내합니다. 미공개·조회 오류·본인 근거 누락은 완료로 처리하지 않습니다. 실제 계정의 결과는 변경하지 않습니다.

관리자의 팀 진행 상황 가이드는 팀 선택 → 진행률·확인 사항 조회 후 팀원 선택 → 수행 기록 확인 → 연결된 문서 산출물 펼쳐 보기의 4단계입니다. 관리자 읽기 권한을 그대로 사용하며 작업·담당 배분·산출물을 변경하지 않습니다. 조회 실패·연결 변경·버전 불일치는 완료로 처리하지 않습니다.

관리자의 동료 평가 시작 가이드는 중간·최종 회차 확인 → 예시 중간 평가 일정 저장 → 평가 시작과 팀별 제출 현황 확인의 3단계입니다. 가이드가 채운 일정을 직접 저장하면 회차가 시작되며, 팀별 제출 현황을 직접 확인합니다. 시작 후 팀 구성 고정과 참여자 수를 확인하고, 실제 조회된 팀별 제출 현황에서 확인을 마쳐야 완료합니다. 저장·개방 실패와 조회 오류는 진행 성공으로 처리하지 않으며, 다시 시작하거나 새로고침하면 미설정 회차부터 시작합니다.

관리자의 리포트 생성·공개 가이드는 생성 조건·반영 비율 확인, 전체 팀 미공개 리포트 생성, 팀원 점수·작업 근거 검토, 전체 팀 공개, 공개 결과 확인을 안내합니다. 모든 팀의 평가가 마감되고 제출된 예시로 시작하며, 반영 비율은 처음 생성할 때 확정됩니다. 생성·조회·공개가 실패하면 다음 단계로 진행하지 않습니다. 계산 근거는 직접 펼쳐 확인하고 공개 확인 창도 직접 확정합니다. 재시작·새로고침 시 리포트와 반영 비율이 초기화되며 실제 계정에는 반영되지 않습니다.

사용 가능한 모든 가이드는 상단의 간단한 단계 표시와 강조 대상 주변의 말풍선으로 안내합니다. 말풍선은 스크롤·화면 크기에 맞춰 버튼을 가리지 않는 방향으로 배치하며, 산출물 등록 창에서는 입력 영역 상단에, 작업 완료 창에서는 확정 버튼 위에 표시합니다. 산출물 안내는 입력 폼과 함께 스크롤되어 편집 영역을 상시 차지하지 않습니다. 안내 위치로 이동할 수 있으며 설명은 항상 표시하고, 각 단계의 확인·저장·제출·공개 버튼과 모달에서도 같은 말풍선 안내를 사용합니다.

시작 목록은 추천 흐름만 강조합니다. 단계 막대는 완료한 단계와 진행 중인 단계를 구분하며 건너뛰기 동작은 제공하지 않습니다. 말풍선에서는 직접 눌러야 할 버튼명을 강조하고, 화면에 배치할 공간이 부족하면 관련 영역 앞이나 상세 영역 안에 설명을 배치해 내용이 가려지지 않도록 합니다.

가이드 완료 화면은 같은 역할의 다음 이용 가능한 가이드·가이드 목록·자유 탐색으로 연결합니다. 역할별 마지막 가이드에는 다음 버튼을 표시하지 않습니다. 목록은 방금 진행한 팀원·관리자 탭으로 열리며, 다음 가이드는 독립된 새 예시로 첫 단계부터 시작합니다. 자유 탐색은 가이드 시작 전 역할과 기존 자유 탐색 데이터로 돌아갑니다.

팀 자료 검색 가이드의 원문 단계는 조회 전에는 원문 열기를 안내하고, 답변과 연결·버전·인용 범위가 일치하는 원문이 정상 조회되면 강조된 원문과 인용문·근거 위치 비교로 안내를 바꿉니다. 원문을 닫으면 열기 안내로 돌아가고, 로딩·실패·다른 자료 조회는 비교 완료 상태로 안내하지 않습니다.

팀 관리 목록의 가이드는 대상 팀의 행 전체를 피해서 말풍선을 위·아래에 배치하여 진행률과 작업 현황을 가리지 않습니다. 좁은 화면의 팀 카드도 전체 영역을 보호합니다.

관리자 안내는 수행 기록·산출물 원문·평가 회차 행·리포트 계산 수치를 피해 배치합니다. 산출물 원문과 계산 근거를 연 뒤에는 비교·검토 안내로 바뀌며, 다른 작업이나 리포트 대상 팀을 선택하면 안내 대상을 다시 선택하도록 설명합니다. 원문 조회 중·실패·버전 불일치는 비교 가능한 상태로 안내하지 않습니다.

‘안내 위치’ 또는 ‘가이드로 돌아가기’는 현재 단계에 필요한 화면·탭·팀·작업·평가 회차를 복원하고, 대상을 숨기는 목록 필터를 해제합니다. 작업 상세의 내부 탭도 복원하며 화면이 준비된 뒤 강조 대상으로 이동합니다. 가이드 단계나 저장한 예시 데이터는 초기화하지 않으며, 저장하지 않은 입력이 있는 화면을 떠날 때는 기존 변경 사항 확인을 유지합니다.

안내와 연결된 창에서는 설명이 스크롤 밖으로 나가면 창 상단에 ‘가이드 안내 위치’를 표시합니다. 이 버튼은 입력과 창을 유지한 채 설명으로 이동합니다. 말풍선은 읽을 영역뿐 아니라 다음에 누를 실제 버튼도 함께 피해서 배치합니다.
