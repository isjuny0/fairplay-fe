# 프론트엔드 공통 규칙

[README로 돌아가기](../README.md)

## 공통 드롭다운

선택 상자는 `src/dropdowns.css`의 공통 토큰을 사용합니다. 기본 `select`와 스페이스·팀·역할 선택, 일정 카테고리 및 날짜·시간 팝업에 흰 배경·얇은 테두리·초록 선택 강조를 적용합니다. 기본 선택 상자의 라벨·필수 검증·키보드·변경 이벤트는 유지하며 `appearance: base-select` 지원 브라우저에서는 펼친 목록도 같은 스타일로 표시합니다. 미지원 브라우저는 스타일이 적용된 선택 상자와 운영체제의 기본 목록으로 대체됩니다.
