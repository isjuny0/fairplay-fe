## 개선 내용

- 모바일 입력 글자를 16px로 지정해 iOS의 작은 입력 글자 자동 확대 조건을 피합니다.
- 주요 실행 버튼, 알림·할 일 버튼, 읽음 버튼, 모바일 메뉴와 평가 점수 선택 영역의 높이를 최소 44px로 확보합니다.
- 팝업의 높이를 동적 화면 높이에 맞추고, 넘치는 목록은 안에서 스크롤합니다. 할 일 카드의 음수 여백을 모바일에서 제거해 오른쪽이 잘리지 않게 합니다.
- 공지 상세의 작성자·등록일을 모바일에서는 두 줄의 정보 행으로 배치합니다.
- 타임라인의 고정 작업명 칸을 144px로 줄여 날짜 막대도 함께 보이게 합니다. 작업명은 두 줄까지 표시하고, 모바일에서는 열 너비 조절기를 숨깁니다.
- 알림함으로 이동할 때 이전 스페이스·팀 문맥을 전달합니다. 팀에서 들어온 경우 모바일 메뉴를 펼쳐 팀 메뉴로 돌아갈 수 있으며, 선택된 팀 메뉴는 표시하지 않습니다.
- 작성 창 하단 버튼에 기기의 안전 영역 여백을 적용합니다.
